## Selected projects

**[OptGraph](https://github.com/Arrav-SP/OptGraph)**: Do LLVM optimisation passes interact differently depending on the program? OptGraph measures pairwise pass interactions on 129 programs (LLVM test-suite, PolyBench, cBench) and predicts them for programs it has not seen. The hypotheses were registered before the experiments and the tests are Holm-corrected. One of the four claims was not supported, and the results say so.
`Python` `LLVM` `scikit-learn`

**[FinTwin](https://github.com/Arrav-SP/FinTwin)**: A PostgreSQL performance bench. It runs synthetic banking workloads, records database telemetry every second, and trains models that predict latency and throughput before a workload runs. It then checks those predictions against real runs (280 runs, 383k operations).
`Python` `PostgreSQL` `FastAPI` `React` `Docker`

**[RegWatch](https://github.com/Arrav-SP/RegWatch)**: Turns the meeting minutes of India's drug regulator (CDSCO) into a structured dataset. LLM extraction is scored against a 200-item hand-labelled set (Cohen's κ 0.84 on the committee's decision). A fine-tuned BiomedBERT baseline predicts decisions from the application text.
`Python` `LLMs` `OCR` `NLP`

**[linux-hrtimer-os-project](https://github.com/Arrav-SP/linux-hrtimer-os-project)**: How Linux high-resolution timers work inside the kernel, and how precisely user programs actually wake up under CPU load. Compares WSL2 with native Fedora, 6,000 measurements per environment.
`C` `Linux kernel`

**[Life Planner](https://github.com/Arrav-SP/LIFE-PLANNER)**: An offline-first planner PWA with tasks, calendar, habits, a study timer and reminders. CI runs database row-level-security tests and Playwright end-to-end tests. [Live demo](https://life-planner-xxft.vercel.app)
`TypeScript` `React` `Supabase`

**[MediVault](https://github.com/Arrav-SP/MediVault)**: A private health-record vault. Upload lab reports, extract and sanity-check the results, and track medications and conditions. In development.
`TypeScript` `Next.js` `Supabase`
